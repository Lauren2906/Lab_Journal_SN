For the data visualisation, the R-package igraph was used, in combination with the base-function ‘plot’. As the data contained information on directed relationships, these were modeled as such. For both graphs, the position of the nodes were kept stable, to show the changes in ties. To accomplish this, the Davidson-Harel layout algorithm was used. This algorithm puts closely connected nodes close to each other, while pushing the lesser connected nodes to the outside (Stulp, n.d.). Importantly, this algorithm does keep isolated nodes within the network, rather than creating a ring outside of it. As I used the same layout for both Wave 1 and Wave 2, this ensured that there are no unreasonably long ties, when isolates in Wave 1 get ties in Wave 2. This algorithm also minimises the amount of overlap between the nodes. Furthermore, the graphs represent nodes with neutral attitudes as ‘pink’ and people with positive attitudes as ‘purple.’ Lastly, the size of the nodes is dependent on density. This was done to examine whether people with more positive attitudes may have more ties than others.

1.1.2.2 Density

As shown above, the networks in both Wave 1 and Wave 2 seem relatively sparse. This is also reflected when calculating their density. To calculate the density of a network, the function “as.network” from the network package was used. This function automatically replaces all missing values with 0, meaning that everyone who did not answer the question about who they hang out with, is seen as having no out-going ties. Concretely, the density of the network shows how many of the possible network ties are actually realised in a network (Tolsma and Hofstra 2022). Thus, a density of 1, means that 100% of all possible ties are actually made, where a density of 0 means that 0% of all possible ties are observered. For the networks in the Michigan learning community the density was .027 and .019, in Wave 1 and Wave 2 respectively. Thus, only 2.7% of all possible ties were actually present in Wave 1, which decreased even further in Wave 2, to only 1.9%. This is a very low density for network, especially when comparing it to friendship networks in classrooms, which are usually between .2 and .4 (Tolsma and Hofstra 2022). Of course, a Michigan learning community is not the same as classroom, as an average classroom is smaller than the learning community, and the students in Michigan do not take all their classes together. However, even comparing the Michigan learning community to a small world network shows that the learning community has a very low density.

1.1.2.4 Reciprocity

Secondly, I calculated the reciprocity of the network. This was done by using the “reciprocity” function in the igraph package. This function calculates the probability of an out-going tie from ego being returned by alter. Similar to density, a value of 1 for reciprocity means that 100% of all out-going ties are reciprocated, and a value of 0 means that none of the out-going ties are met with in-coming ties. The reciprocity in Wave 1 for the Michigan learning community is .471 and in Wave 2 this is .444. This means that, overall, about 45% of all out-going ties are reciprocated. As this paper looks into friendship networks, by asking who people hang out with, it makes sense that a large portion of the ties are reciprocated. If ego hangs out with alter, alter also hangs out with ego. However, more than half of the ties are not reciprocated, which can mean that ego and alter have different ideas about who they hang out with, or what the threshold is for nominating someone as a friend. The reciprocity measure will be slightly skewed by replacing the missing values with 0, as all in-coming ties for those ego’s are automatically not reciprocated, even if in reality they may be.

Path length and average reach

To gain further insight into potential clustering of civic attitudes in the networks, I calculated the average path length and average reach for both Wave 1 and Wave 2. Average shortest path length refers to the the average lowest number of steps for all pairs of nodes in a network (Tolsma and Hofstra 2022). Concretely, what this means is that for every node the shortest path (through the least other nodes) is calculated for every other node. In these calculations, only connected nodes are taken into account, as isolates cannot be reached. The average for all nodes is then calculated. In Wave 1, the average shortest path is 4.841, meaning that the average connected ego has to go through 4.841 nodes to get to every other alter. This number slightly decreases in Wave 2, leading to an average of 4.592. Thus, connected nodes have to go through slightly fewer other nodes to reach every other alter.

Based on this average shortest path length, the average reach was calculated. This measure indicates what degree of other nodes ego can reach within the network, through the existing ties (Tolsma and Hofstra 2022). This number is then averaged for all nodes in a network. In Wave 1, the average reach was .218%, meaning that the average node can reach .218% of other nodes. Again, this number decreases for Wave 2, to .171%.

Combining the decreasing average path length with the decreasing density, indicates that there are more isolates in Wave 2, as the amount of ties decreases, while the nodes that are connected can more easily reach each other. This is also reflected in the average reach, as this decreases between Wave 1 and 2. As isolates have an average reach of 0, an increase in isolates will also lead to a lower average reach.

1.1.2.5 Segregation

Finally, after gaining more insight in the networks, I calculated Moran’s I segregation index. As was to be expected based on visual inspection, there is not much segregation in the network. I calculated Moran’s I using the ape package, which automatically row standardises. This means that the calculation assumes that each node is influenced equally by its neighbourhood, regardless of how large its neighbourhood is (Tolsma and Hofstra 2022). Thus, it is tested whether nodes are similar to the average of their neighbours. As there is no clear segregation in the network, I went through a few steps to see whether there is any degree of segregation.

Firstly, I just looked at segregation based on direct ties. This returned the expected result: Neither in Wave 1 nor in Wave 2 is there evidence of segregation. In Wave 1, Moran’s I is -0.014 (p = 0.942) and in Wave 2 it is -0.018 (p = 0.917). This means that the observed network does not differ significantly from the expected network, when there is no segregation. In fact, for both waves the observed and expected networks get very similar values, indicating that civic attitudes are spread throughout the network, rather than being clustered.

1.2.2.1 Interpretation

The results show that this model converges well, as the overall maximum convergence ratio (.103) is smaller than .25, and all the convergence t-ratio’s are smaller than .1. As this is the simplest possible model, it makes sense that it converges well.

For the network dynamics the simple model shows that the network is not very dense, which matches with the findings in the descriptive section. There is a significant outdegree effect (b = -2.634, SE =.080), meaning that the chances of observing an outgoing tie are significantly lower than observing an incoming tie. Overall, nodes create relatively few ties with others. When a tie is formed, it is likely to be reciprocated, as is evident from the value for reciprocity, which is positive and significant (b = 2.208, SE = .172).
